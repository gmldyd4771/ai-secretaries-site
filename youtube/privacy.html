한국어

  • Heeyong Routine Uploader는 운영자 본인 1명만 자기 YouTube 채널에서 사용하는 개인용 도구입니다. 다른 사용자의 가입이나 로그인을 받지 않습니다.
  • 이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
  • 권한은 youtube.upload(운영자가 승인한 영상 업로드)와 youtube.readonly(승인한 채널이 운영자 채널인지, 업로드 상태 확인)만 사용합니다.

  • YouTube API로 받은 정보(영상 주소·업로드 상태)는 운영자 본인에게만 알리며, 제3자에게 제공하거나 판매하지 않습니다.

English

  • Heeyong Routine Uploader is a personal tool used only by its operator with the operator's own YouTube channel. It does not accept sign-ups or logins from other users.
  • This tool uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.
  • It uses only the youtube.upload scope (to upload videos the operator approved) and the youtube.readonly scope (to confirm the authorized channel is the operator's and to check upload status).
  • It uploads only videos and text the operator filmed or wrote. It does not collect other users' data, comments, or subscriber information.
  • Information received from YouTube API Services (video URL, upload status) is shown only to the operator and is never shared with or sold to third parties.
  • Access tokens are stored only on the operator's own computer. Access can be revoked at any time via Google security settings; revoked tokens are no longer used and are deleted from the operator's computer.
