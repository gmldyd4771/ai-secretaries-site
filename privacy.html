시행일 / Effective: 2026-11-07

한국어

  • 이 앱은 운영자 본인 계정에서만 사용하는 개인용 백업 도구입니다.
  • Google Drive 권한은 drive.file 하나만 사용하며, 이 앱이 만든 파일에만 접근합니다. 다른 Drive 파일은 읽지 않습니다.
  • 백업 파일은 운영자 본인의 Google Drive에만 저장하며, 제3자에게 제공하거나 판매하지 않습니다.
  • 백업은 4주 동안 보관한 뒤 삭제합니다.
  • 인증 토큰은 운영자의 컴퓨터 키체인에만 보관합니다.

English

  • This app is a personal backup tool used only with the operator's own Google account.
  • It uses only the drive.file scope and accesses only files it creates. It does not read other Drive files.
  • Backups are stored only in the operator's own Google Drive and are never shared with or sold to third parties.
  • Backups are kept for 4 weeks and then deleted.
  • Access tokens are stored only in the operator's local keychain.
